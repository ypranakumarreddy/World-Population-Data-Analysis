# World Population Exploratory Data Analysis

This project analyzes global population data using Python and Pandas. It explores trends in population, growth rates, and density across countries and continents, and visualizes key insights with charts and heatmaps.

## Files
- `Pandas 101 - Exploratory Data Analysis in Pandas.ipynb` — Main analysis notebook
- `world_population.csv` — Dataset

## How to Use
1. Open the notebook in Jupyter.
2. Run the cells to see the analysis and visualizations.

## Key Insights
- Asia has the highest average country population.
- Africa has the fastest population growth rate.
- Population and density vary greatly by continent.
